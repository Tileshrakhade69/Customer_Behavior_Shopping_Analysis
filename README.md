# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview

**Customer Shopping Behavior Analysis** is an end-to-end Data Analytics project focused on understanding customer purchasing patterns, product performance, subscription behavior, discount usage, customer segmentation, and revenue trends.

The project covers the complete analytics workflow — from **data loading and exploratory data analysis in Python to SQL analysis in PostgreSQL, Power BI dashboard development, business reporting, and presentation**.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior
* Identify revenue and sales patterns
* Find top-performing products and categories
* Compare subscribers and non-subscribers
* Analyze discount usage and its impact
* Segment customers based on previous purchases
* Analyze repeat customer behavior
* Identify revenue contribution across age groups
* Build an interactive business dashboard
* Generate actionable business insights

---

## 📊 Dataset

The dataset contains **3,900 customer records** with information related to customer demographics, purchases, products, subscriptions, discounts, shipping, payments, and reviews.

### Key Columns

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount (USD)
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Promo Code Used
* Previous Purchases
* Payment Method
* Frequency of Purchases
* Location
* Size
* Color
* Season

## 🚀 How to Run

### Python Analysis

Open the Jupyter Notebook:

```text

```

Install the required libraries:

```bash
pip install pandas matplotlib sqlalchemy psycopg[binary]
```

Run the notebook cells sequentially to reproduce the data analysis and EDA.

Open the SQL file and execute the queries in PostgreSQL.
